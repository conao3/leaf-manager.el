* Overview

~leaf-manager~ provides an interactive interface for managing your [[https://github.com/conao3/leaf.el][leaf]]-based Emacs configuration. It lets you edit, add, and organize leaf blocks in your init.el through a dedicated buffer with convenient keybindings.

[[https://raw.githubusercontent.com/conao3/files/master/blob/leaf-manager.el/leaf-manager.gif]]

* Requirements

- Emacs 26.1 or later
- [[https://github.com/conao3/leaf.el][leaf]]
- [[https://github.com/conao3/leaf-convert.el][leaf-convert]]
- [[https://github.com/conao3/ppp.el][ppp]]

* Installation

~leaf-manager~ is available on MELPA. Install it with your preferred package manager:

#+begin_src emacs-lisp
(leaf leaf-manager
  :ensure t)
#+end_src

* Usage

Run ~M-x leaf-manager~ and enter the package names you want to configure. When you're finished adding packages, type ~nil~ to complete the selection.

A dedicated buffer opens where you can edit the leaf blocks. The buffer provides these keybindings:

| Key       | Action                            |
|-----------+-----------------------------------|
| ~C-c C-c~ | Commit changes to your init.el    |
| ~C-c C-e~ | Evaluate the buffer               |
| ~C-c C-k~ | Discard changes and close         |

* Customization

** Core Settings

- ~leaf-manager-file~ - Path to your init.el file (default: =~/.emacs.d/init.el=)
- ~leaf-manager-recursive-edit~ - When non-nil, use recursive editing mode

** Template Variables

Control how leaf-manager generates your init.el:

- ~leaf-manager-template~ - The format string for the output file
- ~leaf-manager-template-feature-name~ - Feature name (default: "init")
- ~leaf-manager-template-summary~ - File summary
- ~leaf-manager-template-commentary~ - Commentary section content
- ~leaf-manager-template-copyright-from~ - Copyright start year
- ~leaf-manager-template-copyright-to~ - Copyright end year (nil for current year)
- ~leaf-manager-template-copyright-name~ - Copyright holder name
- ~leaf-manager-template-author-name~ - Author name
- ~leaf-manager-template-author-email~ - Author email
- ~leaf-manager-template-license~ - License header text
- ~leaf-manager-template-local-variables~ - Local variables specification

** Appearance

- ~leaf-manager-header-line~ - Face for the header line in the edit buffer
- ~leaf-manager-edit-header-template~ - Format string for the edit buffer header
